# EndForge Releases

Repositorio oficial de distribución de **EndForge**, la aplicación de escritorio educativa para Windows. Aquí se publican los instaladores de las versiones oficiales y estables, junto con sus notas de versión.

## Objetivo de la aplicación

**EndForge** es una plataforma educativa interactiva enfocada en la enseñanza progresiva del lenguaje de programación **C++**. Su objetivo es acompañar al estudiante desde los fundamentos de la programación hasta temas más avanzados mediante lecciones estructuradas, ejercicios prácticos y evaluaciones.

La aplicación de escritorio integra las herramientas necesarias para desarrollar y practicar código dentro de un entorno organizado, procurando reducir la configuración manual necesaria para comenzar a aprender.

## Características principales

1. **Ruta de aprendizaje:** organiza los contenidos en temas y niveles progresivos, desde los conceptos fundamentales hasta estructuras de programación más avanzadas.
2. **Prácticas de programación:** permite trabajar con proyectos y ejercicios de C++ dentro de un entorno diseñado para el aprendizaje.
3. **Seguimiento del progreso:** registra el avance del estudiante y permite consultar sus resultados de aprendizaje.
4. **Sincronización con la nube:** integra funciones de conexión con el ecosistema web de EndForge para gestionar la sesión y sincronizar el progreso compatible.
5. **Persistencia local:** conserva información de configuración y progreso en el equipo para facilitar la continuidad entre sesiones.

## Descargar e instalar

1. Accede a la sección [Releases](https://github.com/jeannn1902/EndForge-Releases/releases) de este repositorio.
2. Descarga el instalador correspondiente a la versión que deseas instalar.
3. Ejecuta el archivo `.exe` en un equipo Windows y sigue las instrucciones del asistente.
4. Abre EndForge y, si deseas utilizar las funciones de cuenta y sincronización, inicia sesión con tus credenciales.

## Requisitos mínimos del sistema

- **Sistema operativo:** Windows 10 o Windows 11 de 64 bits.
- **Procesador:** Intel Core i3 o equivalente de AMD.
- **Memoria RAM:** 2 GB como mínimo.
- **Almacenamiento:** 150 MB de espacio disponible como referencia; el espacio requerido puede variar según los componentes instalados.
- **Conexión a Internet:** necesaria para iniciar sesión y utilizar las funciones que dependen de los servicios en la nube.

Se recomienda contar con espacio adicional para los proyectos, ejercicios y archivos generados durante el uso de la aplicación.

## Versiones y actualizaciones

Las versiones oficiales se publican en la sección [Releases](https://github.com/jeannn1902/EndForge-Releases/releases). Cada publicación puede incluir su instalador, número de versión, notas de cambios y correcciones correspondientes.
