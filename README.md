# EndForge Releases

Repositorio oficial para la distribución y despliegue de instaladores ejecutables de la aplicación de escritorio **EndForge**. En este espacio se publican las versiones compiladas oficiales y sus actualizadores automáticos (`.exe`) listos para entornos Windows.

---

## Objetivo de la Aplicación

**EndForge** es una plataforma educativa interactiva diseñada para la enseñanza progresiva del lenguaje de programación **C++**. La aplicación de escritorio actúa como el cliente nativo principal, proporcionando un entorno de ejercitación y evaluación de código sin necesidad de instalar o configurar manualmente compiladores pesados o cadenas de herramientas complejas.

Su propósito principal es ofrecer un espacio fluido, estructurado y enfocado en la práctica continua, guiando al estudiante desde la sintaxis básica hasta el diseño de algoritmos avanzados mediante módulos de retos y teoría clara.

---

## Cómo Funciona

1. **Orquestación de Prácticas:** La aplicación organiza el contenido pedagógico en módulos y bloques de retos interactivos, permitiendo al usuario navegar entre lecciones y ejercicios estructurados.
2. **Evaluación de Código:** Incorpora un visor de código con resaltado de sintaxis y una terminal interactiva que simula la compilación y ejecución de programas C++ en tiempo real.
3. **Sincronización de Progreso:** Se conecta con el ecosistema web de EndForge para validar credenciales, sincronizar estadísticas de rendimiento, insignias obtenidas e historial de actividad del estudiante.

---

## Instrucciones de Instalación

1. Diríjase a la sección **Releases** en el panel derecho de este repositorio.
2. Descargue el instalador ejecutable más reciente (por ejemplo, `EndForge-Setup-v1.10.2.exe`).
3. Ejecute el archivo descargado en su equipo con **Windows** y complete el asistente de instalación.
4. Inicie la aplicación e ingrese las credenciales de su cuenta de **EndForge** para habilitar la sincronización de datos.

---

## Requisitos Mínimos del Sistema

* **Sistema Operativo:** Windows 10 o Windows 11 (64-bit).
* **Procesador:** Intel Core i3 o equivalente AMD.
* **Memoria RAM:** Mínimo 2 GB.
* **Almacenamiento:** 150 MB de espacio disponible en disco.
* **Conexión a Internet:** Requerida para autenticación de sesión y sincronización con la base de datos.
